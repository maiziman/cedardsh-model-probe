CedarDSH Model Probe - Windows one-click setup

中文

1. 把这个解压后的插件文件夹放进 CedarDSH Desktop 程序文件夹；它应与 CedarDSH-Desktop.exe 和 dsh.cmd 相邻。
2. 关闭 CedarDSH Desktop，也关闭通过 dsh.cmd 打开的 CedarDSH 窗口。
3. 双击 Install-Model-Probe.cmd。
4. 安装成功后重新打开 CedarDSH Desktop。进入“设置 > 插件 > 全局插件”，搜索 model-capabilities 即可确认。

卸载：关闭 CedarDSH Desktop，然后双击 Uninstall-Model-Probe.cmd。卸载不会删除已经保存到模型设置中的能力。

English

1. Put this extracted plugin folder inside the CedarDSH Desktop folder, beside CedarDSH-Desktop.exe and dsh.cmd.
2. Close CedarDSH Desktop and any CedarDSH window started through dsh.cmd.
3. Double-click Install-Model-Probe.cmd.
4. Reopen CedarDSH Desktop. Check Settings > Plugins > Global Plugins and search for model-capabilities.

To remove the plugin, close CedarDSH Desktop and double-click Uninstall-Model-Probe.cmd. Removal keeps capabilities already saved in model settings.
